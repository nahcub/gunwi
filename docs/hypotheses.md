# 지표–민원 가설 (B 역할 산출물)

민원 원자료가 없어 "지표와 민원의 상관관계"를 계산할 수 없다. 이 문서는 그 대신
무엇을 했는지, 보고서·웹에서 어떻게 읽어야 하는지 정리한다. 산식 원칙은
`docs/methodology.md` §5, 가설 원문은 `data/hypotheses.json` 이다.

## 무엇이 어디서 나오나

```
data/hypotheses.json  (가설 H1~H7, 근거 E1~E2, 사분면 Q1)   <- 사람이 고치는 유일한 곳
   ├─ tools/build.py        -> public/data/hypotheses.json   웹 '민원 가설' 카드·사분면
   ├─ tools/export_excel.py -> 엑셀 '가설' 시트
   └─ tools/figures.py      -> 그림2(사분면) · 그림5(가설 구조도)
```

## 가설 한눈에 보기

| ID | 지표 | 유형 | 방향 | 민원 분야 |
|---|---|---|---|---|
| H1 | 고령화율 | 수요형 | + | 생활시설, 도로·보행 |
| H2 | 노령화지수 (H1 보조) | 수요형 | + | 생활시설 |
| H3 | 인구밀도 | 수요형 | ± | 교통·주차, 폐기물·환경 |
| H4 | 고령인구 1천명당 경로당 | 부족형 | − | 생활시설 |
| H5 | 노후 경로당 비율 | 노후형 | + | 생활시설, 조명·안전 |
| H6 | 위험지정 세천 | 노후형 | + | 상·하수도, 도로·보행 |
| H7 | 상수도보급률 | 부족형 | − | 상·하수도 |

각 가설의 근거·주의·검증 방법 전문은 `data/hypotheses.json` 또는 엑셀 '가설' 시트에 있다.
이 표는 요약이다 — 문구를 바꿀 때는 json 을 고치고 이 표의 해당 칸만 맞춘다.

**유형**: 수요형 = 불편을 겪는 사람이 많다 / 부족형 = 시설이 모자라 설치·확충을 요구한다 /
노후형 = 시설이 낡아 고장·보수를 요구한다. 부족형과 노후형은 같은 시설에서도 방향이 반대다.

**전부 `가설(미검증)` 이다.** 보고서에 "~할 것이다", "~로 추정된다"로 쓰고
"~이다", "상관관계가 있다"로 쓰지 않는다.

## 사분면 (Q1) 읽는 법

노후 경로당 비율(x) × 고령화율(y), 각각 8개 읍면 중앙값으로 나눈다.

- 오른쪽 위(두 지표 모두 중앙값 초과) = **가설 H1·H5 를 먼저 검증할 후보**. 2025-12: 의흥면, 산성면
- 점수·가중치·순위가 아니다. "의흥면이 1위"라고 쓰지 않는다
- 부계면은 노후 비율이 가장 높지만 고령화율이 중앙값 아래, 삼국유사면은 고령화율이
  가장 높지만 노후 비율이 중앙값 바로 아래다 — 경계 근처 읍면은 시점에 따라 바뀔 수 있다

## 지표끼리의 상관 (그림3) 읽는 법

민원과의 상관이 **아니다.** 지표 쌍이 같이 움직이는지 본 것이고, n=8 이라
|ρ| ≥ 0.738 일 때만 우연과 구분된다.

| 관찰 | 해석 | 보고서에 쓸 문장 예 |
|---|---|---|
| 고령화율–노령화지수 0.79 | 같은 현상 | "두 지표는 같은 고령화를 다른 분모로 측정하므로 하나로 본다" |
| 노령화지수–고령인구 1천명당 경로당 0.93 | 분모 효과 | "인구가 적은 면일수록 1천명당 경로당이 많게 계산된다(H4 주의)" |
| 시설 지표 3개 vs 고령화율 \|ρ\| ≤ 0.41 | 다른 축 | "인구 측 취약과 시설 측 취약은 서로 다른 지역에서 나타난다" |

## 근거 사실 (검증 자료 아님)

- **E1 살피소 제보**: 군위군 87건 중 현수막 37건(43%), 도로시설 13·교통시설 13(합 30%).
  처리기관 단위라 읍면 구분이 없다 → 군위군 민원 구성의 배경으로만 쓴다 (그림4)
- **E2 포트홀 민원**: 군위군 안 4건(우보면 2, 효령면 2). 표본 부족으로 상관 계산 불가

## 하지 않은 것과 이유

- **종합 점수·순위**: 가중치 근거가 없다(`methodology.md` §3). 사분면이 대신하지 않는다
- **민원과의 상관계수**: 민원 원자료(`COMPLAINT_INTERNAL`) 미확보
- **포트홀로 검증**: 4건뿐
- **민원빅데이터 API(시군구 단위)**: 읍면 차이를 검증할 수 없다. 군 전체 분야 구성 참고용으로만 가능
